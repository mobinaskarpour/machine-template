# THE MACHINE — Demo Template

Reusable executive AI OS template. Customer demos are generated by configuring JSON packs — not by forking business logic.

**Codex should primarily edit:**

- [`demo.config.json`](demo.config.json)
- [`branding/`](branding/)
- [`config/`](config/)
- [`industries/<industry>/`](industries/)
- [`mock-data/`](mock-data/)

**Do not rewrite** `src/components/**` UI or recommendation engines unless a bug requires it.

## Quick start

```bash
npm install
npm run validate-demo
npm run dev
```

Open [http://localhost:3456](http://localhost:3456)

## Scripts

| Script | Purpose |
|--------|---------|
| `npm run dev` | Dev server |
| `npm run lint` | ESLint |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run test` | Vitest smoke |
| `npm run build` | Production build |
| `npm run validate-demo` | Config path checks |
| `npm run generate-demo` | Stub demo generator |
